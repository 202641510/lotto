# 🎰 Streamlit 로또 번호 생성기

Streamlit을 활용하여 1부터 45 사이의 중복 없는 6개 로또 번호를 생성하고, 최대 5개까지의 이력을 관리하는 Web 애플리케이션입니다.

## 📌 주요 기능

* **자동 번호 생성**: 1~45 범위 내에서 중복 없이 6개의 번호를 생성하여 오름차순으로 정렬.
* **이력 관리 (FIFO)**: 최근 생성된 번호 세트를 최대 5개까지 화면에 표시하며, 5개를 초과하면 가장 오래된 이력을 자동 삭제.
* **시각적 UI (로또 공 디자인)**: 
  * 1~10번: 🟡 노란색
  * 11~20번: 🔵 파란색
  * 21~30번: 🔴 빨간색
  * 31~40번: 🟢 초록색
  * 41~45번: 🟣 보라색
* **기록 초기화**: 한 번의 클릭으로 모든 생성 기록을 초기화하는 기능 제공.

## 🚀 실행 방법

### 1. 패키지 설치

터미널에서 아래 명령어를 실행하여 필요한 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행

아래 명령어를 입력하여 로또 번호 생성기 앱을 실행합니다.

```bash
streamlit run app.py
```
